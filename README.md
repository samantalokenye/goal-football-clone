GOAL Football Clone

A responsive football news website inspired by the GOAL.com website. This project was created as part of my frontend internship to practice building a professional-looking website using HTML5, Tailwind CSS, and JavaScript.

🚀 Live Demo

https://samantalokenye.github.io/goal-football-clone/

📂 Repository link 

https://github.com/samantalokenye/goal-football-clone

🛠️ Technologies Used

* HTML5
* Tailwind CSS
* CSS
* JavaScript
* Git & GitHub
* GitHub Pages

✨ Features

* Responsive GOAL-inspired header and navigation
* Desktop, tablet, and mobile layouts
* Mobile navigation menu
* Latest News page
* Article Details page
* Featured football news
* Breaking News section
* Team News section
* Latest Videos section
* Responsive news cards
* Footer with navigation and social links

📄 Pages

* Homepage — Featured stories, breaking news, latest news, team news, and videos.
* Latest News — Displays football news articles with categories, descriptions, and publication times.
* Article Details — Displays an individual article with its category, headline, image, author, publication date, content, and related stories.

📱 Responsive Design

The website was built using Tailwind CSS responsive breakpoints to provide a consistent experience across:

* Desktop
* Tablet
* Mobile

🎯 Project Objective

The objective of this project was to study the structure and user experience of a professional football news website and independently recreate a similar frontend experience without copying the original website’s source code.
